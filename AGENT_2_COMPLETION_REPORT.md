### **Enhanced Info Command**


**Enhanced Metadata Includes:**
- File size in bytes and MB
- Total word and character counts
- Pages with images/tables statistics
- PDF version, creation/modification dates
- Quality scores and backend information

### **Advanced Section Extraction**
```bash
# Extract specific sections with Markdown output
PYTHONPATH=src venv/bin/python src/pdf_engine.py extract "file.pdf" \
  --sections headers --format markdown --output headers.md

# Extract with JSON format including metadata
PYTHONPATH=src venv/bin/python src/pdf_engine.py extract "file.pdf" \
  --sections all --format json --output content.json
```

**Section Types:**
- `headers` - Extract headings and titles
- `tables` - Extract table content
- `paragraphs` - Extract paragraph text
- `all` - Extract all content (default)
